# 版本记录

## 0.1.3 — 2026-09-24

- 新增可选肥鱼人设，聊天、碎碎念和 Air 报信使用一致口吻，可恢复此前人设。
- 额度查询新增重置等待时间，分别显示可用窗口的预计剩余时间；未知时间不猜测。
- 已有安装升级时保留 `.local` 并更新宿主与桌面补丁；人设可按需启用。

## 0.1.2 — 2026-09-22

- 修复 Windows 窗口层级失步时桌宠被普通窗口遮挡；维护可见窗口顺序且不抢焦点。
- 输入窗口独立管理，显式同步隐藏、最小化、恢复与关闭，菜单期间不重新抬起输入层。
- 渲染器崩溃时复用原作退避重启，补充有界窗口健康日志；主动隐藏和最小化不强制恢复。
- 更新会重建桌面 helper，可能重置临时位置和未提交输入；不声称覆盖所有消失原因。
- 修复阶段已有83项本地串行测试、177项固定上游测试通过；本次发版沿用该记录，仅补相关轻量回归、安装状态和旧版升级/撤销检查，不重复全量测试。

## 0.1.1 — 2026-09-22

- 桌面与 Web 右键菜单中的对话表情、工作和输入催促动画使用中文名称。
- 保留动作 ID、菜单层级/顺序、点击回调及未知自定义动画名称回退。
- 运行逻辑、模型、配置、素材和物理行为不变；补充从 0.1.0 原目录升级的步骤。
- 验证：79 项扩展测试、177 项固定上游测试、8 项本机哈希检查；另执行隔离安装/撤销及旧版本升级检查。

## 0.1.0 — 2026-09-21

首个 JetBrains Air 社区集成版本，兼容 dsh-pet 0.2.11 / DSH 0.1.5-rc.1 / Windows x64。

- Air 工作/输入状态、并行任务合并完成、5 分钟报告与点击确认。
- 自然语言退场、挽留、提醒约定及“一次性下个完成”托付；复用原动画的有界表情。
- 独立授权、Air 身份核对、Codex 额度窗口和用量查询。
- 触屏拖动、原物理甩飞、局部输入区域、长气泡和多屏适配。
- 独立扩展目录、精简文档、锁定原包校验、可复现测试与安装/撤销验证。

验证：79 项扩展回归无跳过通过；原维护环境的 177 项固定上游测试通过、8 个安装哈希一致。发布安装包另验证干净安装、重复安装、未知改动拒绝、动画配置和逐字节撤销。

已知限制：Windows 首版；依赖 Air/Codex 当前日志格式；非 Codex Agent 的完成/额度不保证支持；极快触屏切鼠标可能漏首下。模型措辞和所有硬件/媒体组合未穷尽验收。
